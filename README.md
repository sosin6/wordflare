# Wordflare

Free animated captions for Reels, TikTok & Shorts — generated by AI right in the browser. https://wordflare.app

## How it works
- **No backend.** Whisper (`onnx-community/whisper-base_timestamped`) runs in a Web Worker via transformers.js (loaded from jsDelivr), with WebGPU when available and WASM otherwise. Videos never leave the device.
- **Captions** are rendered on a canvas (`src/captions.js`) for both the preview and the export.
- **Export** records the canvas + audio with `MediaRecorder` (H.264 MP4 when the browser supports it, WebM otherwise).
- **Languages:** English (base), Spanish, Portuguese. Texts live in `locales/*.json`; `scripts/build.mjs` renders one static page per language (`/`, `/es/`, `/pt/`) with hreflang, plus privacy/terms pages, sitemap and robots.
- **Measurement:** Umami (cookieless). Events: `tool_used`, `style_change`, `caption_edit`, `export_start/done/error`, `srt_download`, `fake_door_<feature>`, `fake_door_email_<feature>`, `feedback`, `js_error`, …
- **Fake doors:** translate, autoplace, emojis, brandkit, batch, export4k, longvideo, pro_list. Emails go to a Google Sheet through `tools/leads-apps-script.gs`.

## Config
Everything lives in `src/config.js` (Umami website ID, leads endpoint, limits, model).

## Commands
```
node scripts/build.mjs        # build → dist/
node scripts/serve.mjs 4173   # serve dist locally
node scripts/check-links.mjs  # internal link check
node scripts/smoke-cdp.mjs    # local smoke test with system Chrome (no npm)
npx playwright test           # e2e (CI)
```
Add `?e2e=1` to any URL to use a fake transcription (no model download).

## Deploy
Vercel builds on every push to `main` (`vercel.json`). CI (`.github/workflows/ci.yml`) runs the build, link check, Playwright on desktop + mobile, and Lighthouse.
